The Three Pillars

Why modern operating systems must escape fragile state machines and return to immutable appliances.

🛡️

Play Without Fear

The root filesystem is 100% read-only EROFS. Pull the physical USB drive mid-flight or run destructive commands as root. You cannot brick the system. Every boot starts factory-fresh from identical immutable blocks.

📜

15-Line Declarative Recipes

No monolithic Dockerfiles or fragile shell scripts. Define your appliance's packages, entrypoint, memory, and compositor in 15 lines of plain YAML. Cartilage compiles it rootlessly into compressed EROFS.

⚡

Universal ALSA dmix Engine

Zero background audio daemons. No PulseAudio or PipeWire running inside appliances. Hardware direct audio multiplexing via native kernel ALSA dmix provides multi-stream playback with 0ms startup lag.
